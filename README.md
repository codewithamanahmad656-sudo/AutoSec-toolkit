# 🚀 AutoSec-Toolkit

A lightweight, interactive Python automation wrapper designed to streamline ethical hacking, reconnaissance, and CTF challenges (like TryHackMe). 

## 🎯 Features
* **1-Click Interactive CLI:** No need to memorize complex commands or flags.
* **Automated Workflow:** Handles user inputs and execution smoothly.
* **Beginner Friendly:** Clean and well-structured code for security learners.

## ⚠️ Disclaimer
*This tool is created strictly for **educational purposes and authorized security testing (CTFs)**. Do not target unauthorized systems.*

```bash
git clone https://github.com/codewithamanahmad656-sudo/AutoSec-Toolkit.git

python main.py
